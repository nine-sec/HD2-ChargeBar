# HD2 ChargeBar

## 安装

下载 Releases 页面的最新版本，解压后直接运行 ChargeBar.exe。

## 使用

ChargeBar 是一个鼠标长按可视化提示工具，适用于游戏中武器能正常响应鼠标左键输入的场景。在极端情况下（如布娃娃状态），工具可能无法准确反映实际充能进度。

**显示模式**

按 F1 循环切换三种显示模式：

- 隐藏：不显示充能提示条（默认）
- 呼出：按住鼠标右键时显示
- 置顶：充能提示条始终显示在最前

按 F2 退出程序。

**充能提示**

按住鼠标左键时，充能条开始填充（上限 3 秒）：

- 绿色：正常充能中
- 黄色：已达 2 秒
- 红色：已达 2.5 秒

松开左键后进度清零。
